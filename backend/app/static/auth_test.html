1. Google 註冊 / 登入

按 Google 按鈕後會先嘗試登入；尚未註冊時會出現設定帳密的表單。目前是訪客時，註冊會把訪客升級成正式帳號。

按鈕沒反應或跳出錯誤？
  • Client ID：—
  • Google Cloud Console 的「已授權的 JavaScript 來源」要有 和 http://localhost，存檔後等幾分鐘才生效。
  • 用 127.0.0.1 開頁面時，來源也要另外加 http://127.0.0.1:8000。
  • OAuth 還在「測試中」時，只有測試使用者名單裡的 Google 帳號能登入。

2. 使用者名稱 + 密碼登入

連續錯誤 5 次會鎖定 15 分鐘。

3. 訪客登入

建立一個 guest_ 開頭的臨時帳號。同一 IP 每小時最多 10 個。
